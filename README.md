# AudioFlow Player

Исправленная версия плеера для Windows x64. Исходный файл — `main (3).py`.

Скачайте [архив Windows x64 из релиза](https://github.com/ksenpopova/Gyzlik200/releases/latest). Готовая сборка распространяется каталогом `AudioFlow`: извлеките все файлы из архива и запустите `AudioFlow.exe`. Папка `_internal` должна находиться рядом. Python для запуска сборки не требуется.

Плеер продолжает использовать `%USERPROFILE%\.AudioFlowPlayer\app_data.json`. При первой успешной перезаписи существующего профиля создаётся `app_data.json.bak`. Недоступные файлы остаются в плейлистах. Повреждённый или занятый профиль открывается без записи; причина показана в строке состояния. Для отдельного тестового профиля задайте `AUDIOFLOW_PROFILE_DIR`.

В плейлисте двойной щелчок по треку запускает его. Контекстное меню позволяет изменить порядок или убрать запись из списка. Файл на диске при этом сохраняется. При добавлении файлов диалог показывает целевой плейлист.

Эквалайзер обрабатывает выбранный трек после нажатия «Применить к треку». Следующий трек воспроизводится с оригинальным звуком. Нулевые полосы возвращают оригинальный источник. EQ сохраняет каналы, обрабатывает звук блоками и при необходимости снижает общий уровень, чтобы не обрезать пики. Для EQ поддерживаются форматы, открываемые SoundFile в данной сборке; список форматов Qt для обычного воспроизведения может отличаться. Предел одного задания — 512 МиБ декодированного звука и восемь каналов. Формулы фильтров взяты из [W3C Audio EQ Cookbook](https://www.w3.org/TR/audio-eq-cookbook/).

Сборка из исходников на Windows x64 с Python 3.12:

    py -3.12 -m venv .venv
    & ./.venv/Scripts/python.exe -m pip install -r requirements-build.txt
    & ./.venv/Scripts/python.exe -m unittest -v test_player
    & ./build.ps1 -Python ./.venv/Scripts/python.exe

По умолчанию сборка появляется в `%LOCALAPPDATA%\AudioFlowBuild\dist\AudioFlow`. Тесты создают отдельные временные профили и используют Qt в режиме offscreen.

Перед публичным выпуском остаются проверка на чистой Windows без Python, матрица кодеков и устройств, проверка лицензий и зависимостей, подпись и испытание отдельного установщика. Эта поставка представляет собой переносимый каталог.


## Что исправлено и как проверить

- **Плейлисты:** добавьте два трека и перезапустите приложение. Список, громкость и полосы EQ должны сохраниться. Если временно переименовать копию аудиофайла, запись останется в плейлисте.
- **Воспроизведение:** дождитесь конца первого трека — второй должен запуститься автоматически. Если открыть пустой плейлист, звук должен остановиться.
- **Эквалайзер:** измените полосы и нажмите «Применить к треку». Проверьте, что окно отвечает во время обработки. «Сбросить» возвращает оригинальный звук.
- **Упаковка:** запустите распакованный EXE вместе с каталогом `_internal`. Ресурсы загружаются из каталога приложения.
