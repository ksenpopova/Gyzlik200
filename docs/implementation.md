# Выполнение плана аудита

Проверена переносимая сборка Windows x64 на базе Python 3.12.14. В ней есть собственная Python DLL, библиотеки Qt, мультимедиа и ресурсы. Запуск проверен из посторонней рабочей папки, с системным `PATH` и временным профилем.

| Пункты аудита | Результат |
|---|---|
| F01, F02 | Полная поставка в одном каталоге, пути к ресурсам привязаны к приложению. Установщик из исходного отчёта отсутствует. |
| F03–F06, F13, F14 | Атомарная замена JSON, резервная копия исходного профиля, блокировка записи, сохранение недоступных треков, восстановление параметров EQ. Ошибки профиля показаны в строке состояния; экспорт диагностических логов не реализован. |
| F07, F08, F11 | Автопереход, очистка источника при отсутствии трека, отмена устаревшей операции EQ; повторяющиеся таймеры восстановления убраны. |
| F09, F10, F12, F15, F22 | Фоновая обработка по блокам, стерео сохраняется, пики ограничены масштабированием, есть лимит размера и освобождение временных файлов при штатном закрытии. EQ остаётся обработкой выбранного трека. Очистка после принудительного завершения процесса не проверена. |
| F16–F18 | Добавлены ключи тегов MP4, клавиши на экране EQ проверены, метаданные в основных подписях показываются как обычный текст. Полная матрица форматов и встроенные обложки остаются отдельной работой. |
| F19 | Ограничен профиль, поиск запускается с задержкой, транслитерация кешируется, выдача ограничена 500 результатами. Массовый импорт ещё читает теги в потоке интерфейса. |
| F20 | Добавлены команда сборки и закреплённые версии пакетов. Подпись, SBOM и проверка зависимостей перед публичным релизом остаются в плане. |
| F21, F23 | Двойной щелчок запускает выбранный трек; контекстное меню меняет порядок и удаляет запись из списка. Повторное открытие меню отменяет прежний обработчик скрытия. |
| F24, F25 | Обновлены инструкции и описание EQ, вынесены модули хранения и обработки звука, подписаны кнопки транспорта. Исходная пояснительная записка сохранена как исторический документ. Дальнейшее разделение контроллера и испытания DPI остаются в плане. |

Семь регрессионных тестов прошли: миграция и блокировка профиля, повреждённый JSON, отказ атомарной замены, автопереход и пустой плейлист, стерео и уровни EQ, отмена EQ при смене плейлиста, управление полосой EQ клавиатурой. Отдельная проверка собранного EXE подтвердила запуск, загрузку ресурсов, транслитерацию и создание обработанного WAV.

При первой попытке сборки Qt не мог импортировать `QtWidgets`. В состав попала `icuuc.dll` из каталога Poppler в `PATH`: у неё отсутствовали 20 символов, которые импортирует `Qt6Core.dll`. У системной `icuuc.dll` все 20 есть. Сборка после изоляции `PATH` прошла проверку запуска. Это установленная причина сбоя новой сборки; причина ошибки старого установщика не подтверждена.
